# Architecture Decision Records

This directory holds Architecture Decision Records (ADRs) for CodeSheriff.

Naming convention: `NNNN-short-title.md` (e.g. `0001-sandbox-isolation.md`).

The `/domain-modeling` and `/grill-with-docs` skills create ADRs here when terms or decisions get resolved. If an ADR is missing for an area you're working in, proceed without flagging it.
